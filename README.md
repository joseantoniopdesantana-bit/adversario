# Adversário

Jogo casual de adivinhação de palavras em português do Brasil. O jogo mantém o conjunto de palavras ainda possíveis e, a cada palpite, escolhe o feedback que **menos** reduz esse conjunto — uma partida de palavras que joga de volta.

- **Regimes:** Justo (palavra sorteada e fixa) e Cruel (adversário ativo).
- **Plataforma:** PWA web, sem backend, sem cadastro.
- **Léxico:** pt-BR, com pools curados de ~2k, ~8k e ~18k palavras.

Requisitos completos em [`PRD.md`](./PRD.md).
